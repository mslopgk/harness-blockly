# BlockPy 디자인 v2 — 한국 블록코딩(엔트리·카미봇) 레퍼런스 기반 전면 재설계

## 왜 v2인가 (v1 실패 진단)
v1(시안 B + de-slop + 코발트)은 누적 패치로 일관성이 깨졌고 "칙칙하고 저에너지"로 읽혔다. 원인:
1. **웜그레이 배경(#f6f6f4)** — 한국 블록코딩 사이트는 전부 **쿨 화이트/블루틴트**. 웜톤이 탁하게 보였다.
2. **단색 코발트(#2f6fe0)로 전부 중성화** — ui-ux-pro-max 가 이 제품군(아동 교육 도구)의 **안티패턴으로 "muted colors / low energy"** 를 명시. 에너지는 버그가 아니라 기능이다.
3. 카테고리 색을 크롬에서 걷어내며 **블록 팔레트도 단색 1톤**으로 남겨 밋밋해졌다.

### D. 공통 레이아웃 관습 (엔트리·카미봇 모두)
- **흰 상단바** + 로고/메뉴/프로젝트명, 우측에 계정.
- **왼쪽 = 카테고리 + 블록 팔레트**, **가운데 = 캔버스**, **오른쪽 = 결과 영역**(엔트리 실행화면 / 스크래치 무대).
- **크고 눈에 띄는 초록 시작 버튼** + 빨강 정지.
- 패널은 **평평한 흰 카드 + 헤어라인 보더**, 라운드는 **작게(4~8px)** — 버블리하지 않다.

## v2 디자인 시스템 (확정)

```

--bg:#f2f4f7;            /* 앱 바닥(패널과 대비되는 쿨 그레이) */
--panel:#ffffff;         /* 카드/패널 */
--surface:#f9f9f9;       /* 서피스 */
--line:#e2e2e2;          /* 헤어라인 */
--ink:#2c313d;           /* 본문 */
--muted:#606c73;         /* 보조 */
--faint:#979797;         /* 뮤트 */
--accent:#4f80ff;        /* 프라이머리(엔트리 블루) */
--accent-strong:#3968e6; /* hover/active */
--wash:#ecf8ff;          /* 선택 워시 1 */
--wash-2:#d6e9f4;        /* 선택 워시 2 */
--edge-blue:#bfd8e6;     /* 블루그레이 보더 */

```

### 블록 카테고리 색 (엔트리 4단 톤 채택)
우리 27개 카테고리를 엔트리 13개 의미군에 매핑하고, **각 카테고리마다 default/lighten/darken 3단**을 Blockly 테마에 등록한다.
매핑: Values→FLOW, Collections→MOVING, Operators→SOUND, Access→HARDWARE, Variables→VARIABLE,
Control flow→CALC, Functions→FUNC, Built-ins→JUDGE, Classes→MOVING, Exceptions→LOOKS, Imports→FLOW,
Sugar→VARIABLE, Async→HARDWARE, Text→TEXT, Match→CALC, Types→SOUND, dobotkit→START, tm→MOVING.

### 셰이프 & 효과 (버블리 금지, 한국 사이트 관습)
- 라운드: 패널 **8px**, 버튼/칩 **6px**, 입력 **6px**, 블록은 Blockly 기본(Zelos).
- 그림자: 패널 **없음**(헤어라인으로 분리). 떠 있는 것(팝업/드롭다운)만 `0 8px 24px rgba(44,49,61,.14)`.
- 그라디언트 금지(솔리드). 액센트 워시로 상태 표현.
- 활성 탭: `--wash` 배경 + `--accent` 2px 밑줄 + `--accent` 텍스트.

### 타이포그래피
- UI: `Pretendard, "Noto Sans KR", "Malgun Gothic", system-ui, sans-serif` (한국 사이트 표준 톤)
- 코드: `D2Coding, Consolas, ui-monospace, monospace`
- 스케일: 11 / 12 / 13 / 14 / 16 / 19. 굵기 500(본문) / 700(강조) / 800(브랜드).
- 한글 가독성: `line-height 1.5`, `letter-spacing 0`(한글은 타이트닝 금지).

### 레이아웃 (한국 관습 + 현재 요구 반영)
```
┌ 상단바 56px: [로고 BlockPy][main.py][…][예제][변환][저장][■정지][▶실행] ┐
├──────────────────────────────────────────────────────────────────────┤
│ rail 64 │ 코딩 영역(뷰4 + Blockly/코드)      │ AI 터미널(우측, 상시, 넓게) │
│ 아이콘  │ (블록 팔레트는 Blockly 내부)        │ (드래그 리사이즈)           │
└──────────────────────────────────────────────────────────────────────┘
```
- 우측 결과영역 = 한국 관습(실행화면/무대)의 자리에 **AI 터미널**(사용자 요구: 상시·크게).
- 사이드 도구(파일/변수/실행출력/변환로그/AI/로봇/TM)는 rail 아이콘 → **넓은 팝업**(현행 유지).
- 실행 버튼은 초록 + 크게(엔트리 시작하기 관습).

### 접근성
대비 4.5:1(#2c313d on #ffffff = 12:1 ✓), 포커스 링 `0 0 0 3px rgba(79,128,255,.35)`, 아이콘 버튼 aria-label, `prefers-reduced-motion` 존중, 터치 타깃 ≥36px.

## 구현 규칙
- **기능 회귀 0** — 로직/핸들러/엔드포인트/변환 파이프라인 불변. 스타일·클래스·테마 값만.
- 하드코딩 hex 금지(토큰 참조). 기존 레거시 토큰명은 v2 값으로 리맵.
- 검증: `npm run build` + IR 라운드트립 게이트 + 브라우저 실렌더 확인.
